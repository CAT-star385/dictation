# 📝 注音聽寫練習 Chinese Dictation Practice

> 免費的中文生字聽寫線上練習工具,適合台灣國小、國中學生自學,以及老師、家長協助孩子練習。
> A free online Chinese dictation tool for Taiwanese students (zh-TW).

🔗 **線上使用 / Try it now:** **https://cat-star385.github.io/dictation/**

---

## ✨ 特色 Features

- 🔊 **語音朗讀** — 使用瀏覽器內建 Web Speech API,支援 zh-TW
- 🐢 **放慢朗讀** — 0.25x 速度,適合練習困難字
- 📚 **8 套內建題庫** — 預設一、預設二、常用四字成語、破音字、節慶詞彙、形容詞、學校生活用詞,共 290+ 題
- ✏️ **自訂題庫** — 輸入詞語自動轉注音(使用 pinyin-pro)
- 👩‍🏫 **老師出題模式** — 產生專屬連結傳給學生,點開即用
- 🎯 **錯題重考** — 標記錯誤後可只重考錯題
- 📊 **練習紀錄** — 自動記錄歷史(本機儲存)
- 🌙 **深色模式**
- 📱 **PWA 支援** — 可加到手機主畫面當 APP 用,離線可用
- ⏱ **計時模式** — 5/10/15/30 秒,支援 +30 秒延長
- 🔤 **字體大小調整**
- ⌨️ **鍵盤快速鍵** — ← → 切題、空白鍵朗讀、R 重新朗讀

## 🎓 適合誰 Who is it for?

- **學生**:國小、國中、自學中文者,考前複習聽寫
- **家長**:不用親自念聽寫題給孩子,網站會念
- **老師**:出題給班級練習(老師出題模式產生連結即可分享)
- **中文學習者**:練習注音與聽力

---

## 🚀 怎麼使用

1. 打開網址 → https://cat-star385.github.io/dictation/
2. 選擇題庫(或自己輸入詞語)
3. 點「🔊 朗讀」聽題目
4. 用紙筆寫下你聽到的詞
5. 切下一題,寫完後對答案
6. 標記錯題,可只重考錯的

不用註冊、不用安裝、完全免費。

## 🛠 技術 Tech Stack

- **純前端**:HTML + CSS + JavaScript(無框架、無建置流程)
- **注音轉換**:[pinyin-pro](https://github.com/zh-lx/pinyin-pro) v3.18.2
- **語音合成**:Web Speech API
- **字型**:Google Fonts(Noto Sans TC / Noto Serif TC)
- **儲存**:localStorage(本機,完全不上傳)
- **部署**:GitHub Pages
